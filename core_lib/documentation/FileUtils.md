# Пакет FileUtils

Пакет **`FileUtils`** — это подсистема ввода-вывода (IO), отвечающая за интеграцию файловой системы с бизнес-логикой
фреймворка.
Здесь реализованы механизмы поиска, чтения, кэширования и парсинга YAML-файлов (страниц и тестовых данных), а также
разрешение путей и подстановка переменных.

Основные задачи:

1. **Page Object Engine:** Загрузка, валидация и кэширование описаний страниц (`PageReader`, `YamlPageLoader`).
2. **Test Data Engine:** Индексация тестовых данных и их выдача в зависимости от контекста сценария (`TestDataService`).
3. **Resolvers:** Утилиты для разрешения путей к файлам и интерполяции строк (`PathResolver`, `TestDataResolver`).

## 1. Класс `PageReader`

**Ключевой класс модуля.** Представляет собой объектный интерфейс (Proxy) для работы с конкретной страницей, описанной в
YAML.
Класс реализует механизм **Кэширования (Flyweight)**: файлы страниц сканируются и индексируются один раз, чтобы избежать
тяжелых дисковых операций (`Files.walk`) при каждом обращении к странице в тестах.

### Поля класса

| Поле                   | Модификаторы               | Описание                                                                                                                                  |
|:-----------------------|:---------------------------|:------------------------------------------------------------------------------------------------------------------------------------------|
| **`project`**          | `private final String`     | Имя проекта из метаданных страницы (`PageInfo.project`).                                                                                  |
| **`feature`**          | `private final String`     | Имя фичи из метаданных страницы (`PageInfo.feature`).                                                                                     |
| **`pageName`**         | `private final String`     | Имя страницы (`PageInfo.name`). Используется для поиска.                                                                                  |
| **`pageUrl`**          | `private final String`     | URL страницы (`PageInfo.url`). Критически важное поле.                                                                                    |
| **`elements`**         | `private final Map`        | Карта всех элементов страницы: `Имя элемента` -> `ElementDefinition`.                                                                     |
| **`pagePath`**         | `private final String`     | Абсолютный путь к YAML-файлу на диске (для логов и отладки).                                                                              |
| **`log`**              | `private static final`     | Логгер (SLF4J).                                                                                                                           |
| **`PAGE_CACHE`**       | `private static final Map` | **Глобальный кэш.** `ConcurrentHashMap`. Хранит соответствие: `нормализованное имя` -> `File`. Обеспечивает O(1) доступ к файлам страниц. |
| **`cacheInitialized`** | `private static volatile`  | Флаг состояния кэша. `false` — кэш пуст/не сканировался, `true` — кэш построен. Использует `volatile` для видимости в потоках.            |
| **`LOCK`**             | `private static final`     | Объект-монитор для синхронизации потоков при "ленивой" инициализации кэша.                                                                |

### Конструкторы

| Конструктор                     | Видимость | Логика                                                                                                                                                                                                                                                                                                                          |
|:--------------------------------|:----------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`PageReader(File yamlFile)`** | `private` | Создает экземпляр для конкретного файла.<br>1. Делегирует парсинг классу `YamlPageLoader`.<br>2. Валидирует наличие `PageInfo` (иначе `IllegalStateException`).<br>3. Инициализирует поля (`project`, `feature`, `name`, `url`).<br>4. Валидирует наличие `url`.<br>5. Валидирует наличие хотя бы одного элемента в `elements`. |

### Статические методы (Управление кэшем)

| Метод                                    | Описание и Алгоритм                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`usePageYAML`**<br>(`String pageName`) | **Фабричный метод (Точка входа).**<br>1. Проверяет `cacheInitialized`. Если `false` — входит в `synchronized(LOCK)` блок и вызывает `initPageCache()` (Double-Checked Locking).<br>2. Нормализует запрошенное имя страницы.<br>3. Ищет файл в `PAGE_CACHE`.<br>4. Если файл не найден — бросает `IllegalStateException`.<br>5. Возвращает `new PageReader(file)`.                                                                        |
| **`initPageCache`**<br>(`private`)       | **Сканирование диска.**<br>1. Получает путь `pages_dir` из `RuntimeReader`.<br>2. Вызывает `PathResolver` для получения `Path`.<br>3. Рекурсивно обходит директорию (`Files.walk`).<br>4. Фильтрует файлы `.yaml`/`.yml`.<br>5. Парсит каждый файл (только структуру), извлекает имя страницы.<br>6. Складывает в `PAGE_CACHE`.<br>7. **Валидация:** При обнаружении дубликатов имен бросает исключение со списком конфликтующих файлов. |
| **`normalize`**<br>(`String s`)          | Приводит строку к нижнему регистру и удаляет все пробелы. Используется для нечеткого поиска (например, "Login Page" == "loginpage").                                                                                                                                                                                                                                                                                                     |

### Публичные методы (API)

| Метод                      | Параметры     | Описание                                                                                                                                                                                       |
|:---------------------------|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getPageUrl`**           | -             | Геттер URL. Используется в `NavigationSteps`.                                                                                                                                                  |
| **`getPageName`**          | -             | Геттер имени страницы.                                                                                                                                                                         |
| **`getProject`**           | -             | Геттер имени проекта. Используется для Allure Labels.                                                                                                                                          |
| **`getFeature`**           | -             | Геттер имени фичи. Используется для Allure Labels.                                                                                                                                             |
| **`getPagePath`**          | -             | Геттер пути к файлу.                                                                                                                                                                           |
| **`getElementDefinition`** | `String name` | Ищет описание элемента в карте `elements`. Бросает `IllegalArgumentException`, если элемент не найден.                                                                                         |
| **`getLocator`**           | `String name` | **Основной метод для адаптеров.**<br>1. Получает `ElementDefinition`.<br>2. Проверяет, что локатор не пустой (иначе `ErrorBuilder.raise`).<br>3. Возвращает объект `Locator` (Тип + Значение). |
| **`getSemanticType`**      | `String name` | Возвращает тип элемента (например, "button"). Если тип не указан в YAML, возвращает "generic".                                                                                                 |

## 2. Класс `YamlPageLoader`

Низкоуровневый загрузчик. Изолирует библиотеку **SnakeYAML** и отвечает за преобразование "сырой" Map (из YAML) в
типизированный объект `PageModel`.

### Методы

| Метод                       | Видимость | Описание и Логика                                                                                                                                                                                                                                                                                |
|:----------------------------|:----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`load(String pagePath)`** | `public`  | Загрузка по относительному пути (строка).<br>1. Формирует варианты путей: `.yaml` и `.yml`.<br>2. Пытается найти ресурс в classpath через `getResource`.<br>3. Если не найдено — `ErrorBuilder.raise`.<br>4. Вызывает `parseYaml`.                                                               |
| **`load(File file)`**       | `public`  | Загрузка из объекта `File` (используется в `PageReader`).<br>Создает `FileInputStream` и вызывает `parseYaml`. Оборачивает `IOException` в `RuntimeException`.                                                                                                                                   |
| **`parseYaml`**             | `private` | **Парсинг структуры.**<br>1. Загружает YAML через SnakeYAML.<br>2. Ищет секцию `PageInfo`, заполняет объект `PageInfo`.<br>3. Ищет элементы: либо в секции `elements`, либо в корне (фильтруя PageInfo).<br>4. Вызывает `toElementDefinitions`.<br>5. Возвращает `PageModel`.                    |
| **`toElementDefinitions`**  | `private` | **Маппинг элементов.**<br>Преобразует `Map<String, Object>` в `Map<String, ElementDefinition>`.<br>Поддерживает полиморфизм:<br>1. Проверяет наличие полей `locatorType`/`locatorValue`.<br>2. Проверяет наличие вложенного объекта `locator: {by, value}`.<br>3. Заполняет `ElementDefinition`. |
| **`getResource`**           | `private` | Обертка над `ClassLoader.getResourceAsStream`.                                                                                                                                                                                                                                                   |
| **`asMap`**                 | `private` | Безопасное приведение `Object` к `Map<?,?>` с проверкой типа. Бросает исключение, если структура YAML нарушена.                                                                                                                                                                                  |

## 3. Класс `TestDataService`

Сервис управления тестовыми данными. Реализует паттерн **Data Provider** с привязкой к имени сценария. Использует
`ThreadLocal` для поддержки параллельного выполнения.

### Поля класса

| Поле                       | Описание                                                                                   |
|:---------------------------|:-------------------------------------------------------------------------------------------|
| **`DEFAULT_TESTDATA_DIR`** | Путь по умолчанию: `"src/test/resources/testData"`.                                        |
| **`KEY_SCENARIO`**         | Ключ в YAML файле данных: `"Сценарий"`.                                                    |
| **`KEY_DATA`**             | Ключ в YAML файле данных: `"Тестовые данные"`.                                             |
| **`CURRENT_SCENARIO`**     | `ThreadLocal<String>`. Хранит контекст (имя теста) для текущего потока.                    |
| **`index`**                | `volatile Map`. Глобальный индекс всех загруженных данных: `Имя сценария` -> `Map данных`. |
| **`initialized`**          | Флаг, предотвращающий повторное сканирование диска.                                        |

### Методы

| Метод                         | Видимость     | Логика работы                                                                                                                                                     |
|:------------------------------|:--------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`initIfNeeded`**            | `public sync` | Ленивая инициализация.<br>1. Читает путь `testData_dir` из конфига.<br>2. Вызывает `buildIndex` для сканирования папки.<br>3. Сохраняет результат в поле `index`. |
| **`setCurrentScenario`**      | `public`      | Устанавливает имя текущего теста в `ThreadLocal`. Вызывается в `@Before` методах.                                                                                 |
| **`clearCurrentScenario`**    | `public`      | Очищает `ThreadLocal` во избежание утечек памяти. Вызывается в `@After`.                                                                                          |
| **`get(String key)`**         | `public`      | 1. Находит данные для текущего сценария через `findScenarioDataOrThrow`.<br>2. Ищет запрошенный `key` в данных.<br>3. Бросает исключение, если ключ не найден.    |
| **`getTestDataDir`**          | `private`     | Хелпер. Возвращает путь из `RuntimeReader` или дефолтный.                                                                                                         |
| **`buildIndex`**              | `private`     | Сканирует папку (`Files.walk`), находит все `.yaml` файлы и вызывает для них `processYamlFile`.                                                                   |
| **`processYamlFile`**         | `private`     | Читает YAML файл. Поддерживает как список сценариев (List), так и одиночный сценарий (Map). Вызывает `parseEntry`.                                                |
| **`parseEntry`**              | `private`     | Извлекает из YAML-узла имя сценария и карту данных, кладет их в глобальный `index`.                                                                               |
| **`findScenarioDataOrThrow`** | `private`     | Извлекает имя из `CURRENT_SCENARIO`. Ищет его в `index`. Если данных нет — пишет Warning.                                                                         |

## 4. Класс `TestDataResolver`

Утилита для интерполяции строк (подстановки значений из TestData).

### Поля

* **`REF_PATTERN`**: Регулярное выражение `\{([^}]+)\}`. Ищет подстроки вида `{variableName}`.

### Методы

| Метод                     | Видимость       | Логика                                                                                                                                                                                                                                                      |
|:--------------------------|:----------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`resolve(String raw)`** | `public static` | 1. Принимает строку.<br>2. Если строка соответствует паттерну `{...}`, извлекает имя ключа.<br>3. Делает запрос в `TestDataService.get(ключ)`.<br>4. Возвращает найденное значение.<br>5. Если паттерн не найден, возвращает исходную строку без изменений. |

## 5. Класс `PathResolver`

Утилита для "умного" разрешения путей к файлам. Позволяет указывать в конфигах относительные пути, которые будут
работать и в IDE, и при запуске из JAR.

### Методы

| Метод                         | Видимость       | Алгоритм поиска (`resolve`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:------------------------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`resolve(String pathStr)`** | `public static` | Принимает строку пути. Пробует найти файл в 4 этапа:<br>1. **Абсолютный путь:** Проверяет `Paths.get(pathStr).isAbsolute()` и существование.<br>2. **Ресурсы:** Строит путь относительно `src/test/resources`. Если файл есть — возвращает его.<br>3. **User Dir:** Строит путь относительно рабочей директории проекта (`user.dir`).<br>4. **Classpath:** Пытается найти ресурс через `ClassLoader` и преобразовать URL в URI.<br><br>Если ни один способ не сработал — возвращает относительный путь (как есть) с warning логом. |
