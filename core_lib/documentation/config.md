# Пакет config

Пакет **`config`** отвечает за управление конфигурацией всего фреймворка. Он выступает связующим звеном между
статическими YAML-файлами настроек (лежащими в `resources`) и Java-кодом.

Основные задачи пакета:

1. **Инициализация:** Загрузка глобальных параметров из `runtime.yaml` при старте приложения.
2. **Доступ к данным:** Предоставление типизированных методов (API) для получения значений конфигурации.
3. **Маппинг:** Преобразование YAML-структур в Java-объекты (POJO), например, для конфигураций браузеров.

Пакет реализует паттерн **Singleton** (через статические методы и поля), гарантируя, что конфигурация считывается один
раз и доступна глобально из любой точки фреймворка.

---

## 1. Класс `FrameworkConfig`

Служебный класс для определения путей к ресурсам фреймворка. В данный момент управляет базовой директорией, где хранятся
Page Object файлы.

**Особенности:**

* Позволяет переопределять путь через системные свойства Java (`System.getProperty`), что удобно для CI/CD пайплайнов.

| Метод                 | Видимость       | Описание и Логика работы                                                                                                                                                                                                                 |
|:----------------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`pagesBasePath()`** | `public static` | Возвращает относительный путь к папке с YAML-описаниями страниц.<br><br>**Логика:**<br>1. Считывает системное свойство `pages.basePath` (передается через `-D`).<br>2. Если свойство не задано, возвращает дефолтное значение `"pages"`. |

---

## 2. Класс `RuntimeReader`

Центральный класс конфигурационной системы (Singleton Utility Class).
Отвечает за парсинг `runtime.yaml`, модульных конфигов и специфических настроек браузеров.
Использует библиотеку **SnakeYAML** для разбора файлов.

**Жизненный цикл:**
При первом обращении к классу срабатывает **static блок инициализации**:
1.  Класс ищет файл `runtime.yaml` в classpath (приоритет: `configuration_files/runtime.yaml` -> корень `runtime.yaml`).
2.  Файл парсится в `Map<String, Object>`.
3.  Данные кэшируются в статическом поле `runtimeConfig`.

### Внутренние поля и инициализация

Класс спроектирован так, чтобы загрузка конфигурации происходила автоматически и единожды (Lazy Loading при загрузке
класса).

| Поле / Блок          | Описание                                                                                                                                                                                                                          |
|:---------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`runtimeConfig`**  | `private static final Map<String, Object>`<br>Кэш, хранящий все пары "ключ-значение" из файла `runtime.yaml`. Заполняется один раз при старте.                                                                                    |
| **`SEARCH_PATHS`**   | `private static final String[]`<br>Список путей, по которым фреймворк ищет файл конфигурации (в порядке приоритета):<br>1. `configuration_files/runtime.yaml` (основной путь)<br>2. `runtime.yaml` (корень ресурсов)              |
| **`static { ... }`** | **Статический блок инициализации.**<br>Выполняется JVM при первой загрузке класса `RuntimeReader` в память. Вызывает метод `loadRuntimeYaml()`, гарантируя, что конфиг будет прочитан до первого вызова любого публичного метода. |

### Приватные методы (Внутренняя логика)

| Метод                   | Описание и Алгоритм                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`loadRuntimeYaml()`** | Основной метод инициализации.<br>**Алгоритм:**<br>1. Перебирает пути из массива `SEARCH_PATHS`.<br>2. Пытается открыть `InputStream` ресурса.<br>3. Если файл найден: создает `Yaml` парсер с опцией `SafeConstructor` (для безопасности, запрещает создание произвольных Java-объектов).<br>4. Загружает содержимое YAML в карту `runtimeConfig`.<br>5. При успехе завершает работу (return).<br>6. При ошибке или отсутствии файла — выводит сообщение в `System.err`. |

### Публичные методы доступа (API)

Эти методы используются другими модулями (`core_lib`, `TestUtils`) для получения значений из кэша `runtimeConfig`. Методы извлекают данные из загруженного `runtime.yaml`. Они безопасны к `null` (возвращают дефолтные значения или null, но не падают, если ключ не найден, кроме специфических случаев).

| Метод            | Параметры    | Описание                                                                                                                                                                                                        |
|:-----------------|:-------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getString`**  | `String key` | Извлекает значение по ключу и приводит его к строке via `toString()`. Если ключа нет — возвращает `null`.                                                                                                       |
| **`getInt`**     | `String key` | Извлекает значение и парсит его в `int`. <br>*Риск:* Может выбросить `NumberFormatException`, если в YAML не число. Если ключа нет — возвращает `0`.                                                            |
| **`getBoolean`** | `String key` | Извлекает значение и парсит в `boolean`. Если ключа нет — возвращает `false`.                                                                                                                                   |
| **`getSection`** | `String key` | Возвращает вложенный блок YAML как `Map<String, Object>`.<br>*Пример:* Получение всей секции `retry:` или `cucumber_settings:`.<br>Возвращает пустую Map, если ключ не найден или значение не является секцией. |
| **`getList`**    | `String key` | Возвращает список строк (`List<String>`).<br>*Пример:* Получение списка аргументов запуска.                                                                                                                     |

### Методы загрузки внешних конфигураций

Эти методы работают с файлами, отличными от `runtime.yaml`. Они читают файлы "по требованию" (не кэшируются
автоматически).

| Метод                                            | Описание и Связи                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getModuleConfig`**<br>(`String moduleName`)   | Загружает конфигурацию отдельного модуля (например, `selenium_runtime.yaml`).<br>**Логика:** Ищет файл `{moduleName}.yaml` в корне classpath. Использует `SafeConstructor`.                                                                                                                                                                                                                                                                    |
| **`getBrowserConfig`**<br>(`String browserName`) | **Критически важный метод.** Загружает и маппит конфиг браузера в Java-объект.<br>**Логика:**<br>1. Формирует путь: `configuration_files/browsers_configs/{browserName}.yaml`.<br>2. Создает парсер `new Yaml()` (без SafeConstructor, чтобы разрешить создание POJO).<br>3. Выполняет десериализацию YAML напрямую в класс **`browsers.BrowserConfig`**.<br>**Связь:** Используется в `SeleniumBrowserCapabilities` перед созданием драйвера. |
