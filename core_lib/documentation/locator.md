# Пакет locator

Пакет **`locator`** содержит фундаментальные абстракции для поиска UI-элементов.
Его главная цель — предоставить **универсальный формат описания локатора**, который не зависит от конкретной библиотеки
автоматизации (Selenium, Playwright, Appium).

Это позволяет ядру фреймворка оперировать "чистыми" данными, а задачу превращения их в специфичные объекты (например,
`org.openqa.selenium.By`) переложить на конкретные адаптеры.

---

## 1. Enum `LocatorType`

Перечисление всех поддерживаемых стратегий поиска элементов.
Этот список является единым источником правды для всех модулей: если тип есть здесь, он должен поддерживаться (или
корректно обрабатываться как неподдерживаемый) во всех реализациях драйверов.

**Основные значения:**

| Значение                  | Описание                                              | Применимость     |
|:--------------------------|:------------------------------------------------------|:-----------------|
| **`ID`**                  | Поиск по атрибуту `id`. Самый быстрый и надежный.     | Web, Mobile      |
| **`XPATH`**               | Поиск по XPath выражению. Самый гибкий, но медленный. | Web, Mobile      |
| **`CSS`**                 | Поиск по CSS селекторам. Быстрее XPath.               | Web              |
| **`CLASS_NAME`**          | Поиск по значению атрибута `class`.                   | Web, Mobile      |
| **`NAME`**                | Поиск по атрибуту `name`.                             | Web              |
| **`TAG_NAME`**            | Поиск по имени тега (например, `div`, `button`).      | Web              |
| **`LINK_TEXT`**           | Поиск ссылки по её полному тексту.                    | Web              |
| **`PARTIAL_LINK_TEXT`**   | Поиск ссылки по части текста.                         | Web              |
| **`ACCESSIBILITY_ID`**    | Поиск по идентификатору доступности (content-desc).   | Mobile (Appium)  |
| **`ANDROID_UIAUTOMATOR`** | Native Android селекторы (UiSelector).                | Mobile (Android) |
| **`IOS_PREDICATE`**       | Native iOS предикаты.                                 | Mobile (iOS)     |
| **`IOS_CLASS_CHAIN`**     | Native iOS Class Chain запросы.                       | Mobile (iOS)     |

*Примечание:* Строковые значения в YAML-файлах (`type: css`, `type: accessibility-id`) автоматически маппятся в эти
константы с учетом нормализации регистра и знаков препинания.

## 2. Класс `Locator`

Неизменяемый (Immutable) POJO-класс, инкапсулирующий пару **"Стратегия + Значение"**.
Является основным способом передачи информации о местонахождении элемента между компонентами системы (например, от
`PageReader` к `DriverAdapter`).

### Поля класса

| Поле        | Тип           | Описание                               |
|:------------|:--------------|:---------------------------------------|
| **`type`**  | `LocatorType` | Стратегия поиска (не может быть null). |
| **`value`** | `String`      | Строка-селектор (не может быть null).  |

### Конструктор

| Конструктор                                   | Описание                                                                                                                                                                   |
|:----------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`Locator(LocatorType type, String value)`** | Создает новый локатор.<br>Использует `Objects.requireNonNull`, гарантируя, что создать "битый" локатор без типа или значения невозможно (выбросит `NullPointerException`). |

### Методы

| Метод                     | Описание                                                                                                                                                   |
|:--------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getType`**             | Возвращает тип стратегии поиска.                                                                                                                           |
| **`getValue`**            | Возвращает строку селектора.                                                                                                                               |
| **`toString`**            | Возвращает строковое представление в формате `TYPE:VALUE` (удобно для логов/отладки).                                                                      |
| **`equals` / `hashCode`** | Переопределены для корректного сравнения локаторов по значению. Позволяет использовать объекты `Locator` как ключи в картах или сравнивать их между собой. |
