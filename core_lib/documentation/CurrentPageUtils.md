# Пакет CurrentPageUtils

Пакет **`CurrentPageUtils`** отвечает за управление **контекстом текущей страницы** (Page Context) во время выполнения
тестов.

В архитектуре фреймворка, где используется YAML-подход к Page Object, мы не создаем Java-классы страниц (
`new LoginPage()`). Вместо этого фреймворк должен "знать", на какой странице сейчас находится пользователь, чтобы
правильно разрешать имена элементов (например, "Кнопка Войти") в их локаторы.

**Основные задачи:**

1. **Хранение состояния:** Хранит ссылку на объект `PageReader` (активную страницу).
2. **Потокобезопасность:** Использует `ThreadLocal` для изоляции контекста. Это позволяет запускать сотни тестов
   параллельно: каждый поток будет работать со своей "текущей страницей" и не мешать другим.
3. **Доступ к метаданным:** Предоставляет статические методы для быстрого получения информации о странице (URL, имя,
   проект) для логов и отчетов Allure.

---

## 1. Класс `CurrentPageHolder`

Класс-контейнер, непосредственно управляющий состоянием. Он оборачивает `ThreadLocal` переменную и предоставляет строгие
методы доступа к ней.

**Связи:** Хранит экземпляры класса **`FileUtils.PageReader`**.

### Поля класса

| Поле              | Тип                       | Описание                                                                                                                     |
|:------------------|:--------------------------|:-----------------------------------------------------------------------------------------------------------------------------|
| **`currentPage`** | `ThreadLocal<PageReader>` | Локальная переменная потока. Гарантирует, что каждый поток выполнения (Thread) видит только свою копию объекта `PageReader`. |

### Методы

| Метод                            | Видимость | Описание и Логика работы                                                                                                                                                                                                                                                            |
|:---------------------------------|:----------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`set`**<br>(`PageReader page`) | `public`  | Устанавливает новую активную страницу для текущего потока.<br>Обычно вызывается в шаге навигации (например, `NavigationSteps.openPage`).                                                                                                                                            |
| **`get`**                        | `public`  | Возвращает текущий `PageReader`.<br>**Важная особенность:** Если страница еще не была установлена (значение `null`), метод выбрасывает `IllegalStateException`. Это помогает мгновенно отлавливать ошибки в тестах, когда шаг действия (клик) вызывается до шага открытия страницы. |
| **`remove`**                     | `public`  | Очищает значение в `ThreadLocal`.<br>Критически важен для предотвращения утечек памяти и "загрязнения" контекста при переиспользовании потоков в пуле (ThreadPool). Вызывается в `@After` методах (`BaseTest`).                                                                     |

---

## 2. Класс `PageContext`

Точка входа (Entry Point) для доступа к холдеру. Реализован как **Синглтон** (через статическое поле), обеспечивая
глобальный доступ к контексту страницы из любой части кода (адаптеров, шагов, утилит).

### Поля класса

| Поле         | Тип                              | Описание                                                                                |
|:-------------|:---------------------------------|:----------------------------------------------------------------------------------------|
| **`HOLDER`** | `static final CurrentPageHolder` | Единственный экземпляр холдера на всё приложение. Инициализируется при загрузке класса. |

### Методы

| Метод           | Описание                                                                                                                                                             |
|:----------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getHolder`** | Статический геттер. Возвращает объект `HOLDER`.<br>Используется для вызова методов `set/get/remove`.<br>*Пример использования:* `PageContext.getHolder().set(page);` |

---

## 3. Класс `CurrentPageInfo`

Утилитный класс-фасад (Facade). Предоставляет удобный статический доступ к **метаданным** текущей страницы, скрывая
цепочку вызовов `PageContext.getHolder().get()...`.
Часто используется в `AllureUtils` для разметки отчета или в логах.

Все методы этого класса делегируют выполнение объекту `PageReader`, полученному из контекста.

### Методы

| Метод            | Возвращает | Логика и Связи                                                                                                                   |
|:-----------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------|
| **`getProject`** | `String`   | Возвращает имя проекта (из `PageInfo.project` в YAML).<br>Цепочка вызова: `PageContext -> Holder -> PageReader -> getProject()`. |
| **`getFeature`** | `String`   | Возвращает имя фичи/функционального блока.<br>Используется для группировки тестов в Allure.                                      |
| **`getName`**    | `String`   | Возвращает человекочитаемое имя страницы (например, "Login Page").                                                               |
| **`getUrl`**     | `String`   | Возвращает базовый URL страницы.<br>Может использоваться для валидации того, что браузер открыл верный адрес.                    |
