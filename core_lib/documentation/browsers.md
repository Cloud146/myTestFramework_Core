# Пакет browsers

Пакет **`browsers`** предоставляет архитектурную основу для инициализации и настройки браузеров.
Он реализует паттерн **Abstract Factory** и отделяет данные конфигурации (POJO) от логики создания драйверов.

Главная особенность пакета — его **агностичность** по отношению к движку автоматизации.
Благодаря использованию дженериков (Generics), описанные здесь контракты могут использоваться как для Selenium (
`WebDriver`), так и для Playwright (`Browser`) или Appium (`AppiumDriver`).

Основные компоненты:

1. **Контракты:** Интерфейс фабрики (`BrowserFactory`).
2. **Инструментарий:** Базовый абстрактный класс с утилитами (`BaseBrowserFactory`).
3. **Модель данных:** Объектное представление конфигурации (`BrowserConfig`).

---

## 1. Интерфейс `BrowserFactory<T>`

Единый контракт для всех фабрик браузеров в системе.
Использует Generic-тип `<T>`, определяющий, какой именно объект драйвера будет создан.

**Связь с архитектурой:**
Реализации этого интерфейса (например, `ChromeBrowserDriverFactory`) загружаются динамически через **SPI** (Service
Provider Interface) в `AdapterManager`.

| Метод                                          | Описание                                                                                                                                                                  |
|:-----------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getBrowserName()`**                         | Возвращает строковый идентификатор браузера (например, `"chrome"`, `"firefox"`). Используется диспетчером для выбора нужной фабрики на основе настройки в `runtime.yaml`. |
| **`createDriver`**<br>(`BrowserConfig config`) | Фабричный метод. Принимает универсальный конфиг и возвращает готовый, инициализированный экземпляр драйвера типа `T`.                                                     |

## 2. Класс `BaseBrowserFactory<T>`

Абстрактный класс, реализующий интерфейс `BrowserFactory`.
Служит родительским классом для всех конкретных фабрик (в модулях Selenium/Playwright).

**Назначение:** Вынос общей, не зависящей от движка логики ("boilerplate code"). Это позволяет избежать дублирования
кода при парсинге размеров окна или поиске файлов.

### Утилитарные методы (Protected)

Эти методы доступны только наследникам.

| Метод                                                                    | Логика работы                                                                                                                                                                                                                                                                                                                                                                            |
|:-------------------------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getAbsolutePathFromResources`**<br>(`String folder, String fileName`) | Утилита для поиска локальных драйверов.<br>**Алгоритм:**<br>1. Склеивает папку и имя файла.<br>2. Обращается к `ClassLoader` для поиска ресурса в classpath (папка `target/classes` или внутри JAR).<br>3. Преобразует `URL` ресурса в `URI`, а затем в `File`, чтобы получить валидный абсолютный путь ОС.<br>**Возвращает:** Абсолютный путь (String) или `null`, если файл не найден. |
| **`parseWindowSize`**<br>(`String mode`)                                 | Парсер геометрии окна.<br>**Алгоритм:**<br>1. Проверяет префикс `size:`.<br>2. Разделяет строку по символу `x` (например, `1920x1080`).<br>3. Парсит части в `int`.<br>**Возвращает:** Массив `int[]{width, height}` или `null` при ошибке формата.                                                                                                                                      |

## 3. Класс `BrowserConfig`

POJO (Plain Old Java Object) класс, представляющий собой модель конфигурации браузера.
Структура этого класса **один-в-один** соответствует структуре YAML-файлов в `browsers_configs` (`chrome.yaml` и т.д.).

Класс используется `RuntimeReader`'ом для автоматического маппинга YAML данных.

### Поля и Геттеры

Особенность геттеров этого класса — **Null-safety**. Если поле не указано в YAML, геттеры возвращают безопасные значения
по умолчанию (пустые списки, объекты), предотвращая `NullPointerException` в фабриках.

| Поле                   | Тип            | Описание                                              | Дефолтное значение (Getter) |
|:-----------------------|:---------------|:------------------------------------------------------|:----------------------------|
| **`browser`**          | `String`       | Имя браузера.                                         | `null`                      |
| **`driverVersion`**    | `String`       | Версия драйвера для WDM (WebDriverManager).           | `null`                      |
| **`driverPath`**       | `String`       | Имя файла локального драйвера.                        | `null`                      |
| **`binaryPath`**       | `String`       | Абсолютный путь к исполняемому файлу браузера (.exe). | `null`                      |
| **`headless`**         | `boolean`      | Флаг запуска без GUI.                                 | `false`                     |
| **`window`**           | `WindowConfig` | Вложенный объект настроек окна.                       | `new WindowConfig()`        |
| **`args`**             | `List<String>` | Список CLI аргументов запуска.                        | `empty list`                |
| **`preferences`**      | `List<String>` | Список настроек профиля (Firefox).                    | `empty list`                |
| **`pageLoadStrategy`** | `String`       | Стратегия загрузки страницы.                          | `"normal"`                  |

### Внутренний класс `WindowConfig`

Вспомогательный DTO для секции `window:`.

| Поле       | Описание                                                                                        |
|:-----------|:------------------------------------------------------------------------------------------------|
| **`mode`** | Строка режима (`maximize`, `fullscreen`, `size:...`). Возвращает пустую строку, если не задано. |
