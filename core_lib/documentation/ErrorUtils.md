# Пакет ErrorUtils

Пакет **`ErrorUtils`** предоставляет централизованный механизм обработки исключений (Exception Handling).
Его цель — превратить низкоуровневые технические ошибки (например, `StaleElementReferenceException` от Selenium) в
понятные, информативные сообщения бизнес-уровня, обогащенные контекстом (с чем работали, что делали, где упало).

Также пакет интегрирован с **Allure**, автоматически прикрепляя стектрейсы к отчету при возникновении критических
ошибок.

---

## 1. Класс `FrameworkException`

Базовое Runtime-исключение для всего фреймворка.
В отличие от стандартного `RuntimeException`, оно хранит структурированный контекст ошибки. Это позволяет в будущем
анализировать логи не только по тексту сообщения, но и программно.

### Поля

| Поле           | Описание                                                                                |
|:---------------|:----------------------------------------------------------------------------------------|
| **`action`**   | Название действия, которое привело к ошибке (например, "Click", "Open Page").           |
| **`selector`** | Идентификатор UI-элемента, с которым производилось действие (например, "Login Button"). |
| **`url`**      | URL страницы, на которой произошла ошибка (опционально).                                |

---

## 2. Класс `ErrorBuilder`

Реализует паттерн **Builder** для удобного конструирования и выбрасывания `FrameworkException`.
Инкапсулирует логику форматирования сообщения об ошибке и взаимодействия с Allure.

### Методы (Fluent API)

| Метод                          | Описание                                                                                  |
|:-------------------------------|:------------------------------------------------------------------------------------------|
| **`forAction(String action)`** | **Точка входа.** Создает новый билдер, задавая имя действия.                              |
| **`selector(String s)`**       | Добавляет контекст элемента (селектор/имя).                                               |
| **`url(String u)`**            | Добавляет контекст URL.                                                                   |
| **`causedBy(Throwable t)`**    | Прикрепляет исходное исключение (Root Cause).                                             |
| **`message(String msg)`**      | Задает кастомное сообщение об ошибке. Если не задано, будет сгенерировано автоматическое. |

### Терминальный метод `raise()`

Метод завершает построение ошибки и выбрасывает её.

**Алгоритм работы:**

1. **Allure Attachment:** Если указан `cause` (причина), метод формирует полный стектрейс в виде строки и прикрепляет
   его к отчету Allure как текстовый файл ("Error trace"). Это позволяет не захламлять основные логи гигантскими
   стектрейсами, сохраняя их доступными в отчете.
2. **Форматирование:** Если `customMessage` не задан, формирует строку вида:
   `"{action} failed on '{selector}' at '{url}'"`.
3. **Throw:** Выбрасывает `FrameworkException`.

---

## 3. Класс `ExceptionThrow`

Утилитарный класс-обертка (Wrapper) для безопасного выполнения действий с элементами.
Позволяет сократить boilerplate-код `try-catch` в шагах тестов (`Steps`).

### Методы

| Метод                        | Параметры                             | Описание и Логика                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:-----------------------------|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`elementActionException`** | `action`, `selector`, `Runnable call` | Выполняет переданный код (`call.run()`) внутри блока try-catch.<br><br>**Логика обработки ошибок:**<br>1. Если код выполнился успешно — просто выходит.<br>2. Если поймано исключение `FrameworkException` (значит, оно уже обработано глубже) — пробрасывает его дальше без изменений.<br>3. Если поймано любое другое исключение (например, Selenium Exception):<br>    * Перехватывает его.<br>    * Использует `ErrorBuilder` для создания новой `FrameworkException`.<br>    * Обогащает ошибку контекстом (`action`, `selector`).<br>    * Прикрепляет исходную ошибку как `cause`.<br>    * Выбрасывает новую ошибку. |
