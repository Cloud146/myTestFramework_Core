# Пакет AllureUtils

Пакет **`AllureUtils`** содержит утилиты для динамического управления метаданными отчетов Allure во время выполнения
тестов.

По умолчанию Allure группирует тесты на основе пакетов Java (package name) и имен классов. В модульном фреймворке, где
тесты могут запускаться через Cucumber или абстрактные раннеры, такая структура часто неинформативна.
Этот пакет позволяет подменить техническую группировку на бизнес-ориентированную (на основе данных из YAML страниц).

---

## 1. Класс `AllureUtils`

Статический класс-хелпер, работающий напрямую с `Allure.getLifecycle()`.
Это позволяет модифицировать текущий тест-кейс (Test Result) "на лету", добавляя или удаляя метки (Labels).

### Методы управления иерархией (Suite)

Allure строит дерево отчета на основе трех уровней вложенности: `Parent Suite` -> `Suite` -> `Sub Suite`.

| Метод                  | Параметры     | Описание и Логика                                                                                                                                                                                                                           |
|:-----------------------|:--------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`clearSuiteLabels`** | -             | Удаляет **все** существующие метки группировки (`suite`, `parentSuite`, `subSuite`) из текущего теста.<br>**Зачем:** Чтобы убрать дефолтную привязку к Java-пакетам (например, `tests.DemoQA`) перед установкой своих собственных значений. |
| **`addParentSuite`**   | `String name` | Добавляет метку верхнего уровня (обычно имя Проекта или Продукта). Добавляет только если `name` не пустой.                                                                                                                                  |
| **`addSuite`**         | `String name` | Добавляет метку среднего уровня (обычно имя Фичи или Эпика).                                                                                                                                                                                |
| **`addSubSuite`**      | `String name` | Добавляет метку нижнего уровня (обычно имя Стори или Компонента).                                                                                                                                                                           |

### Комплексные методы

| Метод                                                  | Описание                                                                                                                                                                                                                                                                                                                                                                                             |
|:-------------------------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`updateAllureLabels`**<br>(`parent`, `suite`, `sub`) | Метод-агрегатор для полного перестроения иерархии.<br>**Алгоритм:**<br>1. Вызывает `clearSuiteLabels()` (очистка).<br>2. Последовательно вызывает `addParentSuite`, `addSuite`, `addSubSuite`.<br>**Использование:** Вызывается в `NavigationSteps.openPage()` при переходе на новую страницу, чтобы отчет автоматически перегруппировался под контекст открытой страницы (Project/Feature из YAML). |
