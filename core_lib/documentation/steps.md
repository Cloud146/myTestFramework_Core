# Пакет steps

Пакет **`steps`** содержит классы с реализацией шагов (Step Definitions), которые связывают человекочитаемые сценарии (
Gherkin/Cucumber) с программным кодом фреймворка.

**Архитектурная роль:**
Это "публичный интерфейс" фреймворка для тестировщика. Методы этого пакета:

1. Вызываются Cucumber-ом при совпадении регулярного выражения (`@И`).
2. Вызываются напрямую в Java-тестах (как методы объекта).
3. Оборачивают вызовы в Allure Steps (`@Step`) для красивых отчетов.
4. Делегируют выполнение адаптерам драйверов.

## 1. Класс `MouseSteps`

Реализует шаги для взаимодействия мышью.

### Зависимости

* `AdapterHolder` — для получения доступа к текущему драйверу.
* `ExceptionThrow` — для безопасного выполнения действий с перехватом ошибок.

### Методы (Шаги)

Каждый метод аннотирован `@И` (Cucumber) и `@Step` (Allure).

| Метод / Шаг       | Регулярное выражение                | Описание и Логика                                                                                                                                                                                                                        |
|:------------------|:------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`click`**       | `^Клик по элементу «(.+)»$`         | Выполняет левый клик по элементу.<br>**Алгоритм:**<br>1. Принимает имя элемента (как в YAML).<br>2. Оборачивает вызов в `elementActionException("Клик")`.<br>3. Вызывает `adapter.clickElement(name)`.<br>4. Логирует успех.             |
| **`doubleClick`** | `^Двойной клик по элементу «(.+)»$` | Выполняет двойной клик.<br>**Алгоритм:**<br>1. Принимает имя элемента (как в YAML).<br>2. Оборачивает вызов в `elementActionException("Двойной клик")`.<br>3. Вызывает `adapter.doubleClickElement(name)`.<br>4. Логирует успех.         |
| **`rightClick`**  | `^Правый клик по элементу «(.+)»$`  | Выполняет контекстный клик (ПКМ).<br>**Алгоритм:**<br>1. Принимает имя элемента (как в YAML).<br>2. Оборачивает вызов в `elementActionException("Правый клик")`.<br>3. Вызывает `adapter.rightClickElement(name)`.<br>4. Логирует успех. |

## 2. Класс `NavigationSteps`

Реализует шаги навигации и управления контекстом страницы.

### Методы (Шаги)

| Метод / Шаг    | Регулярное выражение        | Описание и Логика                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------------|:----------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`openURL`**  | `^Перейти по url «(.+)»$`   | Прямой переход по ссылке.<br>Вызывает `adapter.openURL(url)` и логирует действие.                                                                                                                                                                                                                                                                                                                                                                              |
| **`openPage`** | `^Открыть страницу «(.+)»$` | **Ключевой шаг Page Object.** Инициализирует страницу.<br>**Алгоритм:**<br>1. Находит YAML файл страницы через `PageReader.usePageYAML(pageName)`.<br>2. Получает базовый URL из модели страницы.<br>3. Вызывает `openURL(pageUrl)`.<br>4. **Устанавливает контекст:** Сохраняет найденную страницу в `PageContext.getHolder().set(page)`.<br>5. **Обновляет Allure:** Проставляет лейблы (Epic, Feature) в отчете на основе данных из YAML (Project/Feature). |

### Примечание по конструкторам

В классах шагов присутствуют два конструктора:

1. **Пустой (`public ClassName()`)**: Используется Cucumber-ом при создании инстанса шагов через Dependency Injection
   контейнер.
2. **С параметром (`public ClassName(Adapter ignored)`)**: Используется при ручном создании шагов в `BaseTest` (для
   Java-тестов). Параметр игнорируется, так как адаптер всегда берется из `AdapterHolder`, но наличие конструктора
   позволяет удобно инициализировать шаги одной строкой.
