# Пакет data

Пакет **`data`** содержит POJO (Plain Old Java Object) классы, которые служат **моделями данных** для объектного
представления YAML-страниц.
Именно в эти классы десериализуются файлы описания страниц с помощью `YamlPageLoader`.

Эти классы не содержат бизнес-логики (кроме минимальной валидации), их главная задача — структурированное хранение
информации о странице и её элементах.

---

## 1. Класс `PageModel`

Корневая модель, представляющая **весь YAML-файл** страницы целиком.

### Поля класса

| Поле           | Тип                              | Описание                                                                                                                                                            |
|:---------------|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`pageInfo`** | `PageInfo`                       | Объект, содержащий метаданные страницы (заголовок, url, проект). Соответствует секции `PageInfo:` в YAML.                                                           |
| **`elements`** | `Map<String, ElementDefinition>` | Карта элементов страницы. <br>**Ключ:** Человекочитаемое имя элемента (как оно написано в YAML). <br>**Значение:** Объект `ElementDefinition` с описанием локатора. |

### Методы

Класс содержит только стандартные геттеры и сеттеры (`getPageInfo`, `setPageInfo`, `getElements`, `setElements`),
используемые загрузчиком YAML.

---

## 2. Класс `PageInfo`

Модель метаданных страницы. Описывает контекст, к которому относится страница.
Эти данные используются для навигации (`url`), поиска (`name`) и формирования отчетов Allure (`project`, `feature`).

### Поля класса

| Поле          | Тип      | Описание                                                                        | Пример YAML          |
|:--------------|:---------|:--------------------------------------------------------------------------------|:---------------------|
| **`project`** | `String` | Имя проекта или доменной области.                                               | `project: DemoQA`    |
| **`feature`** | `String` | Функциональный блок, к которому относится страница.                             | `feature: Buttons`   |
| **`name`**    | `String` | Уникальное (в рамках проекта) имя страницы. Используется в методе `openPage()`. | `name: Buttons Page` |
| **`url`**     | `String` | Базовый URL страницы. Может быть абсолютным или относительным.                  | `url: /buttons`      |

### Методы

Класс содержит стандартные геттеры и сеттеры.

---

## 3. Класс `ElementDefinition`

Модель, описывающая **один UI-элемент** на странице.
Хранит информацию о том, как найти элемент (локатор) и (опционально) его семантический тип.

### Поля класса

| Поле               | Тип      | Описание                                                                                              | Пример YAML       |
|:-------------------|:---------|:------------------------------------------------------------------------------------------------------|:------------------|
| **`type`**         | `String` | Семантический тип элемента (необязательно). Используется для документации или специфических проверок. | `type: button`    |
| **`locatorType`**  | `String` | Строковое название стратегии поиска (id, xpath, css).                                                 | `by: xpath`       |
| **`locatorValue`** | `String` | Само выражение локатора.                                                                              | `value: //button` |

### Методы (API)

Помимо геттеров/сеттеров, класс содержит важный метод конвертации.

| Метод                   | Возвращает    | Описание и Логика работы                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:------------------------|:--------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`toLocatorTypeEnum`** | `LocatorType` | Преобразует строковое поле `locatorType` в строгий Enum `locator.LocatorType`.<br>**Алгоритм:**<br>1. Проверяет, что строка не пустая (иначе кидает `FrameworkException`).<br>2. **Нормализация:** Удаляет пробелы, переводит в верхний регистр (`toUpperCase`) и заменяет дефисы на нижнее подчеркивание (`replace('-', '_')`).<br>*Это позволяет писать в YAML `accessibility-id` или `css-selector`, а в коде получать `ACCESSIBILITY_ID`.*<br>3. Пытается найти значение в `LocatorType.valueOf()`.<br>4. При ошибке выбрасывает понятное исключение через `ErrorBuilder`. |
