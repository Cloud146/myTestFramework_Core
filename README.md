# Modular Test Automation Framework

**Modular Test Automation Framework** — это современное решение для автоматизации тестирования, построенное на принципах
модульности, инверсии зависимостей (IoC) и разделения ответственности.

Фреймворк поддерживает гибридный подход к написанию тестов:

* **Java (Code-based):** Классические TestNG тесты.
* **Cucumber (BDD):** Человекочитаемые сценарии Gherkin.

Главная особенность — полная абстракция от инструмента автоматизации. Тесты пишутся на едином языке (Core API), а
реализация (Selenium, Playwright) подставляется динамически через модули.

---

## 🏗 Архитектура проекта

Репозиторий состоит из нескольких независимых Maven-модулей:

### 1. `core_lib` (Ядро)

**"Мозг" фреймворка.** Содержит только интерфейсы, контракты и бизнес-логику работы с данными.

* Не зависит от Selenium/Playwright.
* Управляет конфигурацией (`runtime.yaml`).
* Отвечает за Page Object движок (парсинг YAML страниц).

### 2. `TestUtils` (Инструменты)

**"Руки" автоматизатора.** Набор утилит для повседневной работы.

* Базовые классы для тестов (`BaseTest`, `CucumberHooks`).
* Система проверок (`Assertions`) с интеграцией в Allure.
* Листенеры для управления потоками, ретраями и скриншотами.

### 3. `Workspace` (Шаблон проекта)

**"Рабочее место".** Это пример того, как выглядит проект конечного пользователя.

* Содержит структуру папок для тестов, данных и конфигов.
* Этот модуль не является частью библиотеки, а служит шаблоном (Template) для создания новых репозиториев с автотестами.

### 4. `modules/selenium_module` (Драйвер)

**"Исполнитель".** Реализация контрактов ядра на базе **Selenium WebDriver**.

* Загружается динамически через Java SPI.
* Если вам нужен Playwright — вы просто подключаете `playwright_module` вместо этого.

## 🚀 Быстрый старт

### Требования

* Java JDK 17+
* Maven 3.8+

### Сборка и установка

Чтобы собрать фреймворк и установить его в локальный репозиторий (.m2):

```bash
mvn clean install -DskipTests
```
