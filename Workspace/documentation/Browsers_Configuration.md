# Конфигурация браузеров

В данном разделе описана настройка профилей браузеров. Файлы конфигурации располагаются в директории:
`Workspace/src/test/resources/configuration_files/browsers_configs/`

Каждый файл (`chrome.yaml`, `firefox.yaml`, `edge.yaml`) отвечает за параметры запуска соответствующего браузера.

Фреймворк поддерживает гибкую настройку через YAML, включая управление версиями драйверов, аргументами запуска (CLI
flags) и внутренними настройками профиля (Preferences).

## Общая структура конфигурации

Независимо от выбранного браузера (Chrome, Firefox, Edge), структура YAML-файла едина. Ниже приведено описание всех
доступных параметров.

### Управление драйвером и бинарниками

Эти параметры определяют, какой драйвер будет использоваться и какой браузер будет запущен.

| Параметр            | Тип      | Описание                                                                                                                                                                                                               | Приоритет       |
|:--------------------|:---------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------|
| **`driverPath`**    | `String` | Имя файла драйвера, расположенного локально в папке `browsers_drivers`.<br>Если указано, фреймворк ищет этот файл в ресурсах и использует его.                                                                         | **1 (Высокий)** |
| **`driverVersion`** | `String` | Версия драйвера для автоматического скачивания через `WebDriverManager`.<br>Пример: `122.0.6261.94` (Chrome) или `0.34.0` (Gecko).                                                                                     | **2 (Средний)** |
| **`binaryPath`**    | `String` | Абсолютный путь к исполняемому файлу браузера (`.exe`).<br>Используется, если браузер установлен в нестандартную директорию или используется Portable-версия.<br>Если `null`, Selenium ищет браузер в системных путях. | —               |

> **Примечание:** Если `driverPath` и `driverVersion` не указаны (равны `null`), фреймворк автоматически скачает
> последнюю стабильную версию драйвера (`LATEST`).

### Параметры запуска

Настройки, влияющие на поведение окна и режим работы.

| Параметр               | Тип       | Описание                                                        | Возможные значения                                                                                                                                     |
|:-----------------------|:----------|:----------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`browser`**          | `String`  | Служебное поле, указывающее имя браузера.                       | `chrome`, `firefox`, `edge`                                                                                                                            |
| **`headless`**         | `Boolean` | Запуск браузера в фоновом режиме (без графического интерфейса). | `true`, `false`                                                                                                                                        |
| **`pageLoadStrategy`** | `String`  | Стратегия ожидания загрузки страницы.                           | `normal` — ждать полной загрузки (onload).<br>`eager` — ждать DOMContentLoaded (быстрее).<br>`none` — не ждать загрузки.                               |
| **`window.mode`**      | `String`  | Режим отображения окна браузера.                                | `maximize` — развернуть на весь экран.<br>`fullscreen` — полноэкранный режим (F11).<br>`size:WxH` — задать точный размер (например, `size:1920x1080`). |

### Аргументы и настройки (Args & Preferences)

Тонкая настройка профиля браузера.

| Параметр          | Описание                                                                                                                                   | Применимость            |
|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------|:------------------------|
| **`args`**        | Список флагов командной строки (CLI arguments).<br>Пример: `--disable-notifications`, `--incognito`.                                       | Chrome, Edge, Firefox   |
| **`preferences`** | Список внутренних настроек профиля (ключ=значение).<br>В Firefox это аналог `about:config`.<br>В Chrome/Edge это User Profile preferences. | Преимущественно Firefox |

## Примеры конфигураций

### Google Chrome (`chrome.yaml`)

Файл конфигурации для браузера Chrome. Использует `chromedriver`.
Скачать конкретную версию `chromedriver` можно отсюда: https://googlechromelabs.github.io/chrome-for-testing/known-good-versions-with-downloads.json

#### Особенности:

* **args:** Chrome имеет самый обширный набор флагов запуска.
* **Версионирование:** Версия `driverVersion` должна строго соответствовать установленной версии браузера (Major
  version).

```yaml
browser: chrome
driverVersion: null
driverPath: null
binaryPath: null

pageLoadStrategy: eager
headless: false
window:
  mode: maximize

args:
  - --disable-notifications
  - --disable-infobars
  - --disable-gpu
  - --lang=ru
```

---

### Mozilla Firefox (`firefox.yaml`)

Файл конфигурации для браузера Firefox. Использует `GeckoDriver`.
Скачать конкретную версию `GeckoDriver` можно отсюда: https://github.com/mozilla/geckodriver/releases

Firefox имеет отличие: для тонкой настройки используются не `args`, а `preferences` (настройки профиля `about:config`).

Секция preferences принимает список строк в формате `ключ=значение`. Фреймворк автоматически определяет тип данных (
Boolean, Integer, String).

```yaml
browser: firefox
driverVersion: null
driverPath: null
binaryPath: null

pageLoadStrategy: eager
headless: false
window:
  mode: maximize

args:
 - -private

preferences:
  - dom.webnotifications.enabled=false
  - geo.enabled=false
  - pdfjs.disabled=true
  - signon.rememberSignons=false
```

---

### Microsoft Edge (`edge.yaml`)

Файл конфигурации для браузера Microsoft Edge. Использует `chromedriver`.

Настройки идентичны Chrome, так как используется движок Chromium.

```yaml
browser: edge
driverVersion: null
driverPath: null
binaryPath: null

pageLoadStrategy: eager
headless: false
window:
  mode: maximize

args:
  - --inprivate
  - --disable-extensions
```

### Список аргументов запуска (`args`)

Эти флаги передаются в секцию `args` в файлах конфигурации (`chrome.yaml`, `edge.yaml`, `firefox.yaml`).
Большинство флагов специфичны для движка Chromium (Chrome, Edge), для Firefox существуют свои аналоги (обычно через `-`
вместо `--`).

| Аргумент                          | Браузеры     | Описание                                                                                                                                         |
|:----------------------------------|:-------------|:-------------------------------------------------------------------------------------------------------------------------------------------------|
| **`--disable-gpu`**               | Все          | Отключение аппаратного ускорения GPU. Обязательно для стабильности в Docker/Linux средах, помогает избежать падений рендеринга.                  |
| **`--ignore-certificate-errors`** | Chrome, Edge | Игнорировать ошибки SSL-сертификатов (полезно на тестовых стендах с самоподписанными сертификатами).                                             |
| **`--disable-popup-blocking`**    | Chrome, Edge | Отключает блокировщик всплывающих окон (Pop-ups).                                                                                                |
| **`--remote-allow-origins=*`**    | Chrome, Edge | Разрешает WebSocket соединения с любых хостов. Критически важный флаг для стабильной работы Selenium 4.10+ с новыми версиями Chrome.             |
| **`--disable-extensions`**        | Chrome, Edge | Запуск без пользовательских расширений. Ускоряет старт и гарантирует "чистое" окружение.                                                         |
| **`--disable-notifications`**     | Chrome, Edge | Блокировка запросов на отправку уведомлений (Web Push API).                                                                                      |
| **`--disable-infobars`**          | Chrome, Edge | Традиционный флаг для скрытия желтой полосы "Браузером управляет автоматизированное ПО".                                                         |
| **`--no-default-browser-check`**  | Chrome, Edge | Отключает проверку того, является ли браузер браузером по умолчанию при запуске.                                                                 |
| **`--disable-first-run-ui`**      | Chrome, Edge | Отключает диалоговые окна первого запуска (мастер настройки, приветствие).                                                                       |
| **`--no-first-run`**              | Chrome, Edge | Принудительно пропускает задачи первого запуска, даже если браузер запускается впервые в этом профиле.                                           |
| **`--lang=ru`**                   | Chrome, Edge | Принудительная установка языка интерфейса (Locale). Влияет на форматы дат и язык сообщений браузера.                                             |
| **`--incognito`**                 | Chrome, Edge | Запуск в режиме Инкогнито (без сохранения кэша, кук и истории после закрытия).                                                                   |
| **`--headless=new`**              | Chrome, Edge | Запуск без графического интерфейса (новый, более стабильный движок Headless).                                                                    |
| **`--disable-features=...`**      | Chrome, Edge | Отключает специфические функции браузера (перечисляются через запятую). См. примеры ниже.                                                        |
| **`--disable-dev-shm-usage`**     | Chrome, Edge | Заставляет браузер использовать `/tmp` вместо `/dev/shm`. Решает проблему краша вкладки "Aw, Snap!" в Docker контейнерах с ограниченной памятью. |
| **`--no-sandbox`**                | Chrome, Edge | Отключает песочницу безопасности (OS Sandbox). Обязателен при запуске браузера от пользователя `root` (типично для Docker контейнеров).          |
| **`-private`**                    | Firefox      | Аналог режима Инкогнито для Firefox.                                                                                                             |
| **`-headless`**                   | Firefox      | Аналог Headless режима для Firefox.                                                                                                              |
| **`-devtools`**                   | Firefox      | Автоматически открывает панель разработчика (F12) при старте браузера.                                                                           |
| **`-jsconsole`**                  | Firefox      | Открывает отдельное окно консоли ошибок браузера (Browser Console).                                                                              |

#### Примеры отключения функций (`--disable-features`)

Используется для отключения назойливых всплывающих окон и помощников Google/Microsoft:

* **`AutofillAssistant`** — отключает ассистент автозаполнения форм.
* **`TranslateUI`** — отключает предложение "Перевести эту страницу?".
* **`ChromeWhatsNewUI`** — отключает вкладку "Что нового" после обновления браузера.
* **`ChromeTips`** — отключает всплывающие подсказки для обучения пользователя.

### Список настроек профиля Firefox (`preferences`)

Эти настройки передаются в секцию `preferences` в файле `firefox.yaml`.
Формат записи в YAML: `ключ=значение`.

| Ключ настройки (Preference Key)              | Тип         | Описание                                                                                                                              |
|:---------------------------------------------|:------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| **`dom.webnotifications.enabled`**           | `false`     | Полное отключение Web Push уведомлений (аналог `--disable-notifications` в Chrome).                                                   |
| **`geo.enabled`**                            | `false`     | Запрет на запросы геолокации. Сайт не будет спрашивать "Разрешить доступ к местоположению?".                                          |
| **`pdfjs.disabled`**                         | `true`      | Отключение встроенного просмотрщика PDF. Браузер будет скачивать файлы `.pdf` вместо их открытия.                                     |
| **`signon.rememberSignons`**                 | `false`     | Отключение менеджера паролей (не предлагать "Сохранить пароль?").                                                                     |
| **`browser.translation.detectLanguage`**     | `false`     | Отключение панели автоматического перевода страниц.                                                                                   |
| **`intl.accept_languages`**                  | `String`    | Установка предпочитаемого языка (Locale). Например: `en-US, en`.                                                                      |
| **`browser.download.folderList`**            | `2`         | Куда сохранять файлы: <br>`0` = Рабочий стол<br>`1` = Папка "Загрузки"<br>`2` = Кастомная папка (см. ниже).                           |
| **`browser.download.dir`**                   | `String`    | Абсолютный путь для сохранения файлов (работает в связке с `folderList=2`).                                                           |
| **`browser.helperApps.neverAsk.saveToDisk`** | `MIME-Type` | Список MIME-типов для автоматического скачивания без диалога "Сохранить как". <br>Пример: `application/pdf,application/octet-stream`. |
| **`network.http.max-connections`**           | `Integer`   | Максимальное количество одновременных HTTP соединений (для нагрузочного тестирования).                                                |
