# Инструкция: Действия мышью (Mouse Steps)

В этом разделе описаны методы для эмуляции кликов пользователя.
Все методы принимают **имя элемента**, которое должно точно совпадать с ключом в YAML-файле описания текущей страницы.

| Название метода   | Вызов Java                             | Вызов Cucumber                           | Описание                                                                             | Параметры                              |
|:------------------|:---------------------------------------|:-----------------------------------------|:-------------------------------------------------------------------------------------|:---------------------------------------|
| **`click`**       | `mouseSteps.click("Login Button");`    | `* Клик по элементу «Login Button»`      | Выполняет стандартный одиночный клик левой кнопкой мыши по центру элемента.          | `elementName` — имя элемента (String). |
| **`doubleClick`** | `mouseSteps.doubleClick("File Icon");` | `* Двойной клик по элементу «File Icon»` | Выполняет двойной клик левой кнопкой мыши. Используется для специфических элементов. | `elementName` — имя элемента (String). |
| **`rightClick`**  | `mouseSteps.rightClick("Row Item");`   | `* Правый клик по элементу «Row Item»`   | Выполняет клик правой кнопкой мыши (вызов контекстного меню).                        | `elementName` — имя элемента (String). |

# Инструкция: Навигация (Navigation Steps)

Методы для управления адресной строкой браузера и инициализации страниц.

| Название метода | Вызов Java                                  | Вызов Cucumber                     | Описание                                                                                                                                                          | Параметры                                                 |
|:----------------|:--------------------------------------------|:-----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|:----------------------------------------------------------|
| **`openPage`**  | `navigationSteps.openPage("Home Page");`    | `* Открыть страницу «Home Page»`   | **Главный метод навигации.**<br>1. Находит страницу в YAML по имени.<br>2. Открывает её URL.<br>3. Устанавливает эту страницу как "текущую" для поиска элементов. | `pageName` — имя страницы (как в `PageInfo.name` в YAML). |
| **`openURL`**   | `navigationSteps.openURL("https://ya.ru");` | `* Перейти по url «https://ya.ru»` | Открывает произвольный абсолютный URL. Не меняет контекст текущей страницы (фреймворк продолжит искать элементы на старой странице).                              | `url` — ссылка (начинается с http/https).                 |

# Инструкция: Проверки (Assertions)

В этом разделе описаны методы для верификации состояния приложения.
Поддерживаются два типа проверок:

1. **Жесткие (Hard):** Останавливают тест при первой ошибке.
2. **Мягкие (Soft):** Проверяют список элементов и падают только в конце, показывая все найденные ошибки.

---

| Название метода               | Вызов Java                                                | Вызов Cucumber                                                               | Описание                                                                                                        | Параметры                                                                             |
|:------------------------------|:----------------------------------------------------------|:-----------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------|
| **`assertElementTextEquals`** | `assertUtil.assertElementTextEquals("Title", "Welcome");` | `* Проверить текст элемента «Title» с ожидаемым текстом «Welcome»`           | **Жесткая проверка.** Сравнивает текст элемента с эталоном. Если текст не совпадает — тест падает мгновенно.    | `elementName` — имя элемента.<br>`expectedText` — ожидаемый текст.                    |
| **`checkTextConditions`**     | `assertUtil.checkTextConditions("Check Form", list);`     | `* Проверить текст элементов «Check Form»:`<br>`\| Name \| равен \| Ivan \|` | **Мягкая проверка текста.** Позволяет проверить множество полей за раз. Поддерживает разные условия (см. ниже). | `description` — описание проверки.<br>`checks` — список условий (билдер или таблица). |
| **`checkElementStates`**      | `assertUtil.checkElementStates("Check Buttons", list);`   | `* Проверить состояние элементов «Check Buttons»:`<br>`\| Btn \| активен \|` | **Мягкая проверка состояния.** Проверяет физические свойства элементов (виден, доступен).                       | `description` — описание.<br>`checks` — список состояний.                             |

---

### Условия для проверки текста (`checkTextConditions`)

Эти значения используются в столбце **"состояние"** (Condition) при проверке текста. Регистр не важен.

| Условие                    | Описание                                                                      | Пример                                      |
|:---------------------------|:------------------------------------------------------------------------------|:--------------------------------------------|
| **`равен`**                | Полное посимвольное совпадение текста.                                        | Текст "Error 404" равен "Error 404".        |
| **`не равен`**             | Текст элемента НЕ должен совпадать с ожидаемым.                               | Текст "Success" не равен "Error".           |
| **`содержит`**             | Текст элемента должен содержать подстроку.                                    | Текст "Welcome, User!" содержит "User".     |
| **`не содержит`**          | Текст элемента НЕ должен содержать подстроку.                                 | Текст "Welcome" не содержит "Error".        |
| **`равен (без регистра)`** | Сравнение без учета регистра (А == а).                                        | Текст "HELLO" равен (без регистра) "hello". |
| **`пуст`**                 | Текст элемента должен быть пустым (длина 0). Значение в таблице игнорируется. | Поле ввода очищено.                         |
| **`не пуст`**              | Текст элемента должен быть любым, кроме пустого.                              | Поле ввода заполнено.                       |

---

### Состояния элементов (`checkElementStates`)

Эти значения используются в столбце **"состояние"** (State) при проверке свойств элементов.

| Состояние                           | Описание                                                         | Когда применять                                         |
|:------------------------------------|:-----------------------------------------------------------------|:--------------------------------------------------------|
| **`отображается`** / **`виден`**    | Элемент присутствует в коде страницы (DOM) и виден пользователю. | Проверка, что модальное окно открылось.                 |
| **`скрыт`** / **`не отображается`** | Элемента либо нет вообще, либо он невидим (`display: none`).     | Проверка, что лоадер исчез.                             |
| **`активен`**                       | Элемент доступен для взаимодействия (нет атрибута `disabled`).   | Проверка, что кнопка "Отправить" разблокирована.        |
| **`не активен`**                    | Элемент заблокирован (есть атрибут `disabled`).                  | Проверка, что нельзя нажать кнопку до заполнения формы. |
| **`существует`**                    | Элемент присутствует в HTML-коде (DOM), даже если он скрыт.      | Технические проверки наличия скрытых полей.             |
| **`не существует`**                 | Элемента нет в HTML-коде.                                        | Проверка полного удаления элемента.                     |
