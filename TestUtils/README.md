# Модуль TestUtils (Тестовые утилиты)

**`TestUtils`** — это модуль, содержащий инструментарий для написания и выполнения тестов. Если `core_lib` — это "
движок" (backend), то `TestUtils` — это "инструменты управления" (frontend для автоматизатора).

Модуль не содержит бизнес-логики приложения, но предоставляет базовые классы и механизмы, необходимые для любого теста,
будь то UI (Selenium/Playwright) или API.

## Основные задачи модуля

1. **Управление жизненным циклом тестов (Test Lifecycle):**
   Здесь находятся базовые классы (`BaseTest`, `CucumberHooks`), которые отвечают за то, что происходит *до* теста (
   инициализация драйвера, чтение конфига) и *после* него (закрытие браузера, очистка данных).

2. **Интеграция с TestNG и Cucumber:**
   Модуль содержит набор Listeners (слушателей), которые модифицируют поведение стандартных раннеров:
    * Параллельный запуск (`JavaParallel`, `CucumberParallel`).
    * Повторный запуск упавших тестов (`RetryUtil`).
    * Скриншоты при падении (`ScreenshotUtil`).

3. **Механизм проверок (Assertions):**
   Мощная система ассертов (Soft & Hard Assertions), интегрированная с Allure. Позволяет писать проверки как в коде
   Java, так и в Gherkin-сценариях, получая красивые отчеты с таблицами расхождений.

4. **Вспомогательные хелперы:**
   Инициализаторы данных, логгеры сценариев, менеджеры адаптеров.

## Структура пакетов (High-Level)

* **`Assertion`** — Библиотека проверок (сравнение текста, состояний, таблиц).
* **`BaseTest`** — Фундамент для всех Java-тестов.
* **`CucumberUtils`** — Конфигурация запуска BDD сценариев, хуки, фильтрация.
* **`Helpers`** — Служебные классы (AdapterManager, DataInitializer).
* **`JavaParallel`** — Аннотации и логика для параллельного запуска Java-тестов.
* **`RetryUtil`** — Механизм перезапуска (Retry Analyzer).
* **`ScreenshotUtil`** — Создание скриншотов при падении.
