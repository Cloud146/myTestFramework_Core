# Пакет TestUtils.ScreenshotUtil

Пакет **`TestUtils.ScreenshotUtil`** отвечает за создание визуальных доказательств (скриншотов) состояния приложения.
Главная особенность реализации — использование нативного Java AWT Robot вместо стандартного Selenium `TakesScreenshot`.
Это позволяет делать скриншоты **всего экрана ОС**, захватывая не только область веб-страницы, но и системные окна,
алерты браузера, DevTools и панель задач.

---

## 1. Класс `ScreenshotUtil`

Утилитарный класс, содержащий логику захвата изображения и интеграции с Allure Report.

### Методы (API)

| Метод                         | Параметры               | Описание и Алгоритм                                                                                                                                                                                                                                                                                              |
|:------------------------------|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`captureScreenPngBytes`**   | -                       | **Низкоуровневый захват экрана.**<br>1. Инициализирует `java.awt.Robot`.<br>2. Определяет размер экрана через `Toolkit.getDefaultToolkit().getScreenSize()`.<br>3. Создает `BufferedImage` (слепок пикселей).<br>4. Конвертирует изображение в массив байт (`byte[]`) формата PNG.<br>5. Возвращает массив байт. |
| **`takeScreenshot`**          | `String screenshotName` | **Публичный метод для ручного вызова (или шаг Cucumber).**<br>Аннотирован `@Step` и `@И` ("Сделать скриншот...").<br>1. Вызывает `captureScreenPngBytes`.<br>2. Прикрепляет полученный PNG к отчету Allure.                                                                                                      |
| **`takeScreenshotOnFailure`** | `ITestResult result`    | **Метод для автоматического вызова при ошибке.**<br>1. Проверяет валидность `result`.<br>2. Делает скриншот.<br>3. Пытается прикрепить его к упавшему тесту с именем "Screenshot on failure".<br>4. Возвращает `true` при успехе.                                                                                |

### Приватные методы

| Метод                | Логика                                                                                                                                                                                 |
|:---------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`attachToAllure`** | Хелпер для безопасного добавления вложения.<br>Использует `Allure.getLifecycle().addAttachment` с MIME-типом `image/png`. Перехватывает ошибки, если жизненный цикл Allure недоступен. |
| **`safeMethodName`** | Вспомогательный метод для получения имени метода из `ITestResult` без риска получить `NullPointerException`.                                                                           |

## 2. Класс `ScreenshotListener`

Слушатель событий TestNG (`ITestListener`), обеспечивающий автоматическое создание скриншотов при падении тестов без
участия человека.

### Методы (События)

| Метод                                         | Логика работы                                                                                                                                                                                                                                    |
|:----------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`onTestFailure`**<br>(`ITestResult result`) | Срабатывает в момент, когда тест помечается как Failed (Assertion Error или Exception).<br>1. Логирует факт падения.<br>2. Вызывает `ScreenshotUtil.takeScreenshotOnFailure(result)`.<br>3. Логирует результат (удалось ли прикрепить скриншот). |
| **Остальные методы**                          | `onTestStart`, `onTestSuccess`, ...                                                                                                                                                                                                              | Имеют пустую реализацию (заглушки), так как действия требуются только при падении. |
