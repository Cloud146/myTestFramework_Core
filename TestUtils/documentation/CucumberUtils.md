# Пакет TestUtils.CucumberUtils

Пакет **`TestUtils.CucumberUtils`** — это набор инструментов для глубокой интеграции Cucumber BDD с инфраструктурой
фреймворка.
Он решает задачи динамической конфигурации, фильтрации тестов, управления параллелизмом и интеграции с Allure Report.

---

## 1. Класс `CucumberHooks`

Класс глобальных Cucumber-хуков. Наследуется от `BaseTest`.
Его задача — связать жизненный цикл Cucumber-сценария (`Scenario`) с механизмами инициализации драйверов (`BaseTest`) и
системой отчетов (`Allure`).

### Методы (Hooks)

| Метод                                           | Аннотация            | Описание и Логика                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:------------------------------------------------|:---------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`cucumberSetUp`**<br>(`Scenario scenario`)    | `@Before(order = 0)` | **Инициализация окружения перед сценарием.**<br>1. `CucumberAllureScenarioLifecycle.startScenario`: регистрирует старт теста в Allure.<br>2. Добавляет метку `"tag": "Cucumber_Test"` для фильтрации в отчете.<br>3. `TestDataService.initIfNeeded()`: загружает тестовые данные (если еще не загружены).<br>4. `TestDataService.setCurrentScenario`: сообщает сервису имя текущего теста.<br>5. Считывает настройки `retry` из `runtime.yaml`.<br>6. Вызывает `setUp()` родительского класса `BaseTest` (создание драйвера). |
| **`cucumberTearDown`**<br>(`Scenario scenario`) | `@After(order = 0)`  | **Очистка ресурсов после сценария.**<br>1. В блоке `try` вызывает `tearDown()` родителя (закрытие браузера, очистка ThreadLocal).<br>2. В блоке `finally` вызывает `CucumberAllureScenarioLifecycle.stopScenario`, чтобы гарантированно завершить запись в отчет, даже если tearDown упал.                                                                                                                                                                                                                                    |

## 2. Класс `CucumberRuntimeConfig`

POJO-класс конфигурации. Отвечает за парсинг секции `cucumber_settings` из файла `runtime.yaml`.
Класс является **Immutable** (неизменяемым) — все поля `final` и устанавливаются только через конструктор.

### Константы (Ключи YAML)

| Константа          | Значение              | Описание                                     |
|:-------------------|:----------------------|:---------------------------------------------|
| **`SECTION`**      | `"cucumber_settings"` | Имя корневой секции в `runtime.yaml`.        |
| **`KEY_RUN_BY`**   | `"run_by"`            | Ключ стратегии запуска (`tag` / `scenario`). |
| **`KEY_VALUE`**    | `"value"`             | Ключ значения фильтра.                       |
| **`KEY_PARALLEL`** | `"parallel"`          | Ключ включения параллелизма.                 |
| **`KEY_THREADS`**  | `"threads"`           | Ключ количества потоков.                     |

### Поля класса

| Поле           | Тип            | Описание                                        |
|:---------------|:---------------|:------------------------------------------------|
| **`runBy`**    | `String`       | Стратегия фильтрации (валидируется при чтении). |
| **`values`**   | `List<String>` | Список значений фильтра (например, теги).       |
| **`parallel`** | `boolean`      | Флаг: включен ли параллельный режим.            |
| **`threads`**  | `int`          | Количество потоков.                             |
| **`log`**      | `Logger`       | Логгер класса.                                  |

### Конструктор

| Конструктор                  | Видимость | Логика                                                                                                                        |
|:-----------------------------|:----------|:------------------------------------------------------------------------------------------------------------------------------|
| `CucumberRuntimeConfig(...)` | `private` | Приватный конструктор. Используется только внутри статического фабричного метода `load()`. Просто присваивает значения полям. |

### Статические методы (Фабрика)

| Метод        | Видимость | Логика работы                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-------------|:----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`load()`** | `public`  | **Точка входа.**<br>1. Получает секцию настроек через `RuntimeReader.getSection(SECTION)`.<br>2. Проверяет, что секция не пустая (иначе `RuntimeException`).<br>3. Вызывает приватные парсеры (`readRunBy`, `readValues`) для извлечения данных.<br>4. Читает `parallel` (дефолт `false`).<br>5. Читает `threads` (если `parallel=true`, дефолт `4`, иначе `1`).<br>6. Возвращает новый экземпляр `CucumberRuntimeConfig`. |

### Приватные методы (Парсеры)

| Метод                              | Описание и Валидация                                                                                                                                                                                                                       |
|:-----------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`readRunBy`**<br>(`Map config`)  | Извлекает значение `run_by`.<br>**Валидация:** Проверяет, что значение не `null` и не пустое. Приводит к нижнему регистру (`trim().toLowerCase()`).                                                                                        |
| **`readValue`**<br>(`Map config`)  | Вспомогательный метод. Извлекает сырую строку `value`. Проверяет на `null`/пустоту.                                                                                                                                                        |
| **`readValues`**<br>(`Map config`) | Парсит строку значений в список.<br>**Логика:**<br>1. Получает строку через `readValue`.<br>2. Разделяет по запятой (`split(",")`).<br>3. Для каждого элемента делает `trim()` и фильтрует пустые строки.<br>4. Собирает в `List<String>`. |

### Публичные методы (API)

| Метод                                                                  | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:-----------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`applySystemFilter()`**                                              | **Трансляция настроек в System Properties.**<br>Метод берет значения из полей класса и устанавливает их в системные свойства, которые читает Cucumber.<br>**Логика:**<br>• Если `runBy="tag"`: Формирует Tag Expression (например, `"@smoke or @regress"`). Валидирует выражение через `TagExpressionParser`. Устанавливает свойство `cucumber.filter.tags`.<br>• Если `runBy="scenario"`: Формирует Regex (добавляет `^...$`, объединяет через ` |`). Устанавливает свойство `cucumber.filter.name`.<br>• Иначе: Бросает исключение (некорректный `run_by`). |
| **`getRunBy`** / **`getValues`** / **`isParallel`** / **`getThreads`** | Стандартные геттеры для доступа к полям конфигурации.                                                                                                                                                                                                                                                                                                                                                                                             |

## 3. Класс `CucumberParallelListener`

Слушатель TestNG (`IAlterSuiteListener`), позволяющий программно изменять параметры запуска (`testng.xml`) в рантайме.
Используется для управления количеством потоков.

### Методы

| Метод                                    | Логика работы                                                                                                                                                                                                                                                                                     |
|:-----------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`alter`**<br>(`List<XmlSuite> suites`) | 1. Загружает конфиг через `CucumberRuntimeConfig.load()`.<br>2. Определяет `threadCount`: если `parallel=true` берет из конфига, иначе `1`.<br>3. Логирует режим запуска (Параллельный/Последовательный).<br>4. Проходит по всем `XmlSuite` и вызывает `setDataProviderThreadCount(threadCount)`. |

## 4. Класс `ScenarioFilter`

Утилита для предварительной валидации фильтров. Cucumber сам умеет фильтровать тесты, но он делает это молча. Этот класс
нужен, чтобы убедиться, что фильтр **действительно что-то нашел**, и выбросить ошибку, если пользователь опечатался в
теге.

### Методы

| Метод                                                              | Описание и Алгоритм                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`filterScenarios`**<br>(`Object[][] scenarios`, `Config config`) | Принимает массив всех сценариев (от `CucumberRunner`).<br>1. **Логирование:** Выводит в лог имя и теги каждого найденного сценария (для отладки).<br>2. Проверяет, что список сценариев не пуст.<br>3. Собирает множества всех доступных имен (`allScenarioNames`) и тегов (`allTags`).<br>4. **Валидация наличия:** Проверяет, существуют ли запрошенные в конфиге значения (`values`) в собранных множествах. Если нет — пишет WARN лог.<br>5. **Проверка совпадения:** Проверяет, совпадает ли *хотя бы один* сценарий с фильтром. Если нет — бросает `RuntimeException` ("Ни одно из значений не совпало").<br>6. Возвращает исходный массив сценариев (так как реальную фильтрацию уже сделал Cucumber через System Properties). |

## 5. Класс `CucumberAllureScenarioLifecycle`

Ручное управление жизненным циклом сценария в Allure Report. Необходимо для корректной связки Cucumber-TestNG-Allure при
кастомном запуске.

### Поля

| Поле              | Описание                                                                                                       |
|:------------------|:---------------------------------------------------------------------------------------------------------------|
| **`currentUuid`** | `ThreadLocal<String>`. Хранит уникальный идентификатор (UUID) текущего тест-кейса в Allure для данного потока. |

### Методы

| Метод                                 | Логика                                                                                                                                                                                                                                         |
|:--------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`startScenario`**<br>(`Scenario s`) | 1. Генерирует UUID.<br>2. Создает объект `TestResult`.<br>3. Заполняет метаданные: имя, historyId, fullname.<br>4. Конвертирует теги сценария в Allure Labels.<br>5. Запускает тест в Allure Lifecycle (`scheduleTestCase`, `startTestCase`).  |
| **`stopScenario`**<br>(`Scenario s`)  | 1. Получает UUID из ThreadLocal.<br>2. Определяет статус: `FAILED` если `s.isFailed()`, иначе `PASSED`.<br>3. Обновляет статус тест-кейса.<br>4. Останавливает и записывает тест (`stopTestCase`, `writeTestCase`).<br>5. Очищает ThreadLocal. |

## 6. Класс `CucumberConfigInitializer`

Простой фасад (Facade) для инициализации.

### Методы

| Метод               | Описание                                                                                                                                                                           |
|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`initAndFilter`** | 1. Вызывает `CucumberRuntimeConfig.load()` (чтение YAML).<br>2. Вызывает `config.applySystemFilter()` (установка System Properties для Cucumber).<br>3. Возвращает объект конфига. |
