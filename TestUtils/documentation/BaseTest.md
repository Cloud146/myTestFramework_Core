# Пакет BaseTest

Пакет содержит фундаментальный класс, являющийся родителем для всех Java-тестов в проекте (а также базой для
CucumberHooks).
Его задача — инкапсулировать всю "черновую работу" по настройке окружения, инициализации драйверов и очистке ресурсов,
позволяя автору теста сосредоточиться на бизнес-логике.

---

## 1. Класс `BaseTest`

Абстрактный класс, реализующий методы жизненного цикла TestNG (`@BeforeClass`, `@BeforeMethod`, `@AfterMethod`).
Предоставляет наследникам готовые экземпляры шагов (`mouseSteps`, `navigationSteps`) и утилит (`assertUtil`), избавляя
от необходимости создавать их вручную в каждом тесте.

### Поля класса (Protected - доступны в тестах)

| Поле                  | Тип               | Описание                                                                                                                                                     |
|:----------------------|:------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`adapter`**         | `DriverAdapter`   | Прямая ссылка на текущий адаптер драйвера. Полезна, если нужно вызвать низкоуровневый метод, которого нет в шагах. Если `ui_engine` не задан — будет `null`. |
| **`page`**            | `PageReader`      | Ссылка на текущую открытую страницу (изначально `null`, заполняется в ходе теста).                                                                           |
| **`retryCount`**      | `int`             | Количество попыток перезапуска теста (из `runtime.yaml`).                                                                                                    |
| **`assertUtil`**      | `AssertUtil`      | Утилита для проверок (Assertions). Инициализируется автоматически.                                                                                           |
| **`mouseSteps`**      | `MouseSteps`      | Готовый объект с шагами мыши (Click, DoubleClick).                                                                                                           |
| **`navigationSteps`** | `NavigationSteps` | Готовый объект с шагами навигации (OpenPage).                                                                                                                |
| **`log`**             | `Logger`          | Приватный логгер класса.                                                                                                                                     |

### Методы жизненного цикла

Эти методы вызываются TestNG автоматически.

| Метод                                       | Аннотация                              | Описание и Логика                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:--------------------------------------------|:---------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`initData`**                              | `@BeforeClass`                         | **Инициализация ресурсов на уровне класса.**<br>1. Вызывает `FrameworkDataInitializer.initTestData()` — сканирует YAML-файлы с тестовыми данными один раз для всего прогона.<br>2. Читает настройку `retry` из конфига.                                                                                                                                                                                                                                                                     |
| **`scenarioName`**<br>(`Method testMethod`) | `@BeforeMethod`                        | **Логирование начала теста.**<br>1. Принимает метаданные тестового метода (Java Reflection).<br>2. Передает их в `ScenarioLogger`, который выводит имя теста в консоль и устанавливает контекст для `TestDataService`.                                                                                                                                                                                                                                                                      |
| **`setUp`**                                 | `@BeforeMethod`                        | **Инициализация драйвера (Сессия).**<br>1. Читает `ui_engine` из `RuntimeReader` (selenium/playwright).<br>2. Если движок задан:<br>    * Создает адаптер через `AdapterManager`.<br>    * Регистрирует адаптер в `AdapterHolder` (ThreadLocal).<br>    * Инициализирует поля `mouseSteps`, `navigationSteps`, `assertUtil`, передавая им созданный адаптер.<br>3. Если движок не задан (API тесты) — оставляет поля `null`.                                                                |
| **`tearDown`**                              | `@AfterMethod`<br>`(alwaysRun = true)` | **Завершение сессии (Гарантированное выполнение).**<br>1. Получает текущий адаптер из холдера.<br>2. Вызывает `AdapterManager.closeAdapter()` (закрывает браузер).<br>3. В блоке `finally`:<br>    * `AdapterHolder.clear()` — удаляет драйвер из потока.<br>    * `TestDataService.clearCurrentScenario()` — очищает контекст данных.<br>    * `PageContext.getHolder().remove()` — сбрасывает текущую страницу.<br>Это предотвращает утечки памяти и загрязнение контекста между тестами. |
