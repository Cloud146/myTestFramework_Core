## Класс `BaseCucumberRunner`

Абстрактный базовый класс, предназначенный для использования в качестве родителя для Runner-классов в пользовательских
проектах.
Он берет на себя всю сложность настройки TestNG для запуска Cucumber-сценариев, включая динамическую фильтрацию и
управление потоками.

**Назначение:** Реализует паттерн "Template Method" для запуска тестов. Пользователю достаточно унаследоваться от этого
класса и настроить `@CucumberOptions`.

### Динамическая фильтрация и Параллелизм

В классе переопределен метод `scenarios()`, который выступает в роли **Data Provider** для TestNG.

**Логика работы:**

1. **`initConfig`** (`@BeforeSuite`): До старта тестов загружает настройки из `runtime.yaml` (теги, потоки).
2. **`scenarios`**:
    * Получает список всех найденных тестов.
    * Применяет фильтр `ScenarioFilter`, отсеивая тесты, которые не подходят под условия `run_by` (тег или имя).
    * Если включен `parallel: true` (в `runtime.yaml`), тесты распределяются по потокам.

### Методы жизненного цикла

| Метод            | Аннотация                        | Описание и Логика                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-----------------|:---------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`initConfig`** | `@BeforeSuite(alwaysRun = true)` | **Инициализация перед всем прогоном.**<br>1. Вызывает `CucumberConfigInitializer.initAndFilter()`.<br>2. Загружает `runtime.yaml`.<br>3. Применяет системные свойства (фильтры по тегам) для Cucumber-ядра.                                                                                                                                                                                                                                                         |
| **`scenarios`**  | `@DataProvider(parallel = true)` | **Поставщик данных (тестов).**<br>Переопределяет стандартный метод провайдера данных Cucumber.<br>**Алгоритм:**<br>1. Получает список всех найденных сценариев через `super.scenarios()`.<br>2. Передает их в `ScenarioFilter` для дополнительной валидации и фильтрации на основе конфига.<br>3. Возвращает отфильтрованный массив тестов для выполнения.<br>**Важно:** Атрибут `parallel = true` разрешает TestNG запускать полученные сценарии в разных потоках. |
