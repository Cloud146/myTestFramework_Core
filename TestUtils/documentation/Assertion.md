# Пакет TestUtils.Assertion

Пакет **`TestUtils.Assertion`** предоставляет расширенную систему проверок (Asserts) для тестов.
Он включает в себя фасад для вызова проверок, исполнителей (Executors) для жестких и мягких ассертов, модели данных и
утилиты для визуализации результатов в Allure.

---

## 1. Класс `AssertUtil`

Основной фасад пакета. Используется в `BaseTest` и предоставляет единый API для выполнения проверок в тестах и
шагах Cucumber.

### Поля

| Поле                 | Описание                                                                                   |
|:---------------------|:-------------------------------------------------------------------------------------------|
| **`log`**            | Логгер класса (SLF4J).                                                                     |
| **`singleExecutor`** | Экземпляр `SingleAssertionExecutor` для выполнения одиночных жестких проверок.             |
| **`tableExecutor`**  | Экземпляр `TableAssertionExecutor` для выполнения массовых мягких проверок (Soft Asserts). |

### Конструкторы

| Конструктор                           | Описание                                                                                                                             |
|:--------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------|
| **`AssertUtil()`**                    | Пустой конструктор. Используется при создании экземпляра.                                                                            |
| **`AssertUtil(TextAdapter ignored)`** | Конструктор с заглушкой. Нужен для совместимости с PicoContainer (Cucumber DI), чтобы можно было внедрять класс как Step Definition. |

### Публичные методы (API)

| Метод                                                       | Описание                                            | Логика работы                                                                                                                       |
|:------------------------------------------------------------|:----------------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------|
| **`assertElementTextEquals`**<br>(`element`, `expectedRaw`) | Шаг Cucumber: *"Проверить текст элемента..."*.      | 1. Разрешает плейсхолдеры в `expectedRaw` через `TestDataResolver`.<br>2. Делегирует выполнение в `performTextAssertion`.           |
| **`checkTextConditions`**<br>(`description`, `checks`)      | Шаг Cucumber для табличной проверки текста.         | 1. Проходит по списку проверок и разрешает плейсхолдеры `{...}` в значениях.<br>2. Делегирует выполнение в `performTableTextCheck`. |
| **`checkElementStates`**<br>(`description`, `checks`)       | Шаг Cucumber для табличной проверки состояний.      | Делегирует выполнение в `performStateCheckStep`.                                                                                    |
| **`defineAssertionEntry`**<br>(`Map entry`)                 | Метод транформации (`@DataTableType`) для Cucumber. | Преобразует строку Gherkin-таблицы (столбцы: "элемент", "состояние", "значение") в объект `AssertionEntry`.                         |
| **`defineStateEntry`**<br>(`Map entry`)                     | Метод транформации (`@DataTableType`) для Cucumber. | Преобразует строку Gherkin-таблицы (столбцы: "элемент", "состояние") в объект `StateAssertionEntry`.                                |

### Приватные методы (Внутренняя логика)

| Метод                       | Логика работы                                                                                                                                                                                                                                                                                                                                |
|:----------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`performTextAssertion`**  | Аннотирован `@Step`.<br>1. Вызывает `singleExecutor.executeTextAssertion`.<br>2. Логирует успех.<br>3. Перехватывает `AssertionError`, логирует ошибку и выбрасывает обернутый `FrameworkAssertionError`.                                                                                                                                    |
| **`performTableTextCheck`** | Аннотирован `@Step`.<br>1. Прикрепляет таблицу *ожидаемых* значений к отчету (`attachTextChecks`).<br>2. Вызывает `tableExecutor.executeTableTextChecks`.<br>3. Перехватывает `SoftVerificationException`.<br>4. При ошибке: прикрепляет таблицу *расхождений* (`attachAssertionFailureTable`) и выбрасывает исключение с подробным текстом. |
| **`performStateCheckStep`** | Аналогичен `performTableTextCheck`, но вызывает `tableExecutor.executeStateChecks` и использует `attachStateChecks`.                                                                                                                                                                                                                         |
| **`buildFailureMessage`**   | Формирует читаемый текстовый отчет об ошибках для консоли/лога. Собирает все `AssertionFailure` в один форматированный String блок.                                                                                                                                                                                                          |

## 2. Подпакет `executors`

### Класс `SingleAssertionExecutor`

Исполнитель одиночных жестких проверок.

| Метод                                                      | Описание                                                                                                                                                                                               |
|:-----------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`getAdapter()`**                                         | Приватный хелпер. Возвращает текущий драйвер из `AdapterHolder`.                                                                                                                                       |
| **`executeTextAssertion`**<br>(`name`, `expected`, `desc`) | 1. Получает фактический текст элемента через `adapter.getTextFromElement`.<br>2. Сравнивает его с ожидаемым через AssertJ `assertThat().isEqualTo()`.<br>3. Если не совпадает — тест падает мгновенно. |

### Класс `TableAssertionExecutor`

Исполнитель массовых мягких проверок.

| Метод                                      | Описание                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`executeTableTextChecks`**<br>(`checks`) | 1. Создает пустой список ошибок `failures`.<br>2. В цикле проходит по каждой проверке `AssertionEntry`.<br>3. В блоке `try-catch`: получает текст элемента, выбирает условие через `switch` (равен/содержит/пуст) и выполняет проверку AssertJ.<br>4. При ошибке (`AssertionError`) добавляет объект `AssertionFailure` в список, **не прерывая цикл**.<br>5. После цикла: если есть ошибки, выбрасывает `SoftVerificationException`. |
| **`executeStateChecks`**<br>(`checks`)     | Аналогичная логика, но проверяет булевы состояния элемента (`isDisplayed`, `isEnabled`).<br>Поддерживает условия: "виден", "скрыт", "активен", "не активен", "существует", "не существует".                                                                                                                                                                                                                                           |

## 3. Подпакет `helpers`

### Класс `AllureTableUtil`

Утилита для генерации HTML-отчетов.

| Метод                             | Описание                                                                                                          |
|:----------------------------------|:------------------------------------------------------------------------------------------------------------------|
| **`attachTextChecks`**            | Генерирует и прикрепляет к Allure HTML-таблицу с планом проверок (Элемент - Условие - Значение).                  |
| **`attachStateChecks`**           | Аналогично для проверок состояний (Элемент - Состояние).                                                          |
| **`attachAssertionFailureTable`** | Генерирует таблицу с результатами ошибок. Подсвечивает цветом расхождения (Expected - зеленый, Actual - красный). |
| **`attachAssertionFailure`**      | (Deprecated/Alternative) Генерирует простой список ошибок текстом.                                                |
| **`escape(String input)`**        | Приватный метод. Заменяет спецсимволы (`<`, `>`, `&`, `"`) на HTML-сущности для защиты верстки.                   |

### Класс `CheckBuilder`

Реализует Fluent Builder Pattern для создания списков проверок в коде.

| Внутренний класс  | Методы                                                                                                          |
|:------------------|:----------------------------------------------------------------------------------------------------------------|
| **`TextChecks`**  | `add(element, condition, value)` — добавляет проверку.<br>`build()` — возвращает список `List<AssertionEntry>`. |
| **`StateChecks`** | `add(element, state)` — добавляет проверку.<br>`build()` — возвращает список `List<StateAssertionEntry>`.       |

| Статический метод | Описание                        |
|:------------------|:--------------------------------|
| **`text()`**      | Возвращает новый `TextChecks`.  |
| **`state()`**     | Возвращает новый `StateChecks`. |

## 4. Подпакет `model`

Пакет содержит POJO-классы (Plain Old Java Objects) и исключения, необходимые для хранения данных проверок и передачи
информации об ошибках.

### Класс `AssertionEntry`

Модель данных, описывающая одну строку текстовой проверки. Используется в таблицах Cucumber и внутри
`TableAssertionExecutor`.

| Поле            | Тип      | Описание                                          |
|:----------------|:---------|:--------------------------------------------------|
| **`element`**   | `String` | Имя элемента (ключ из YAML страницы).             |
| **`condition`** | `String` | Условие проверки (например, "равен", "содержит"). |
| **`value`**     | `String` | Ожидаемое значение текста.                        |

**Методы:** Стандартные геттеры, сеттеры, конструкторы и переопределенный `toString()` для удобного логирования.

### Класс `StateAssertionEntry`

Модель данных, описывающая одну строку проверки состояния элемента.

| Поле          | Тип      | Описание                                                     |
|:--------------|:---------|:-------------------------------------------------------------|
| **`element`** | `String` | Имя элемента.                                                |
| **`state`**   | `String` | Ожидаемое состояние (например, "виден", "скрыт", "активен"). |

**Методы:** Геттеры, сеттеры, конструкторы, `toString()`.

### Класс `AssertionFailure`

Модель, описывающая зафиксированную ошибку проверки (Failure). Создается, когда фактическое значение не совпало с
ожидаемым.

| Поле            | Тип      | Описание                                    |
|:----------------|:---------|:--------------------------------------------|
| **`element`**   | `String` | Имя элемента, на котором упала проверка.    |
| **`condition`** | `String` | Какое условие проверялось.                  |
| **`expected`**  | `String` | Что ожидалось увидеть (Expected Result).    |
| **`actual`**    | `String` | Что было получено по факту (Actual Result). |

### Класс `FrameworkAssertionError`

Кастомное исключение, наследуемое от `java.lang.AssertionError`.

**Назначение:** Используется для того, чтобы тестовые раннеры (TestNG/Allure) помечали тест статусом **FAILED** (
Красный - логическая ошибка), а не **BROKEN** (Желтый - техническая ошибка/крэш). Выбрасывается при падении жестких
проверок.

### Класс `SoftVerificationException`

Кастомное исключение, наследуемое от `RuntimeException`.

**Назначение:** Служит "контейнером" для передачи списка ошибок из `TableAssertionExecutor` в основной метод теста.
Выбрасывается в конце выполнения мягкой проверки, если список ошибок не пуст.

| Поле           | Тип                      | Описание                                                                      |
|:---------------|:-------------------------|:------------------------------------------------------------------------------|
| **`failures`** | `List<AssertionFailure>` | Список всех накопленных ошибок. Используется для генерации финального отчета. |
