# Пакет TestUtils.JavaParallel

Пакет **`TestUtils.JavaParallel`** предоставляет механизм декларативного управления параллельным выполнением
Java-тестов (TestNG) на уровне классов.
Он позволяет активировать многопоточный режим и задавать степень параллелизма (Thread Pool Size) непосредственно в коде
теста с помощью аннотаций, переопределяя глобальные настройки `testng.xml`.

---

## 1. Аннотация `@ParallelClass`

Пользовательская аннотация времени выполнения (`RetentionPolicy.RUNTIME`), предназначенная для маркировки тестовых
классов, методы которых должны выполняться параллельно.

### Параметры

| Параметр      | Тип   | Дефолтное значение | Описание                                                                                                                                                                                   |
|:--------------|:------|:-------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`threads`** | `int` | `0`                | Определяет количество потоков для выполнения методов данного класса.<br>• `0`: Автоматическое определение (поведение TestNG по умолчанию).<br>• `> 0`: Явное задание размера пула потоков. |

**Пример использования:**

```java
@ParallelClass(threads = 3)
public class LoginTests extends BaseTest { ... }
```

## 2. Класс `ParallelRunListener`

Реализация интерфейса `IAlterSuiteListener` из TestNG API. Этот интерфейс позволяет перехватить управление **до** начала выполнения тестов и программно изменить структуру `XmlSuite` (виртуальное представление `testng.xml`).

**Назначение:** Автоматическая конфигурация параметров `parallel` и `thread-count` для тестов, помеченных аннотацией `@ParallelClass`.

### Метод `alter`

Метод выполняет итеративный анализ структуры тестового сьюта и модифицирует его параметры.

**Алгоритм работы:**
1.  **Итерация:** Проходит по всем объектам `XmlSuite` и вложенным `XmlTest`.
2.  **Сканирование классов:** Внутри каждого теста (`XmlTest`) перебирает список классов (`XmlClass`).
3.  **Поиск аннотаций:**
    *   Получает реальный Java-класс через `xmlClass.getSupportClass()`.
    *   Проверяет наличие аннотации `@ParallelClass` у данного класса.
4.  **Агрегация настроек:**
    *   Если аннотация найдена, устанавливает локальный флаг `enableParallel = true`.
    *   Вычисляет максимальное требуемое количество потоков (`maxThreads`) среди всех классов в текущем `XmlTest` (используя `Math.max` для выбора наибольшего значения из всех аннотаций).
5.  **Применение конфигурации (Modification):**
    *   Если флаг `enableParallel` установлен:
        *   `xmlTest.setParallel(XmlSuite.ParallelMode.METHODS)`: Включает режим параллельного выполнения на уровне методов (`@Test`).
        *   Если `maxThreads > 0`:
            *   `xmlTest.setThreadCount(maxThreads)`: Устанавливает размер пула потоков для методов.
            *   `suite.setDataProviderThreadCount(maxThreads)`: Синхронизирует количество потоков для Data Provider с основным пулом.
    *   Логирует факт активации параллельного режима и итоговое количество потоков.
